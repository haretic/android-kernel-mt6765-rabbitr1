# Stock RabbitOS (Android 12) MediaTek video codec userspace, from out/stock-vendor/tree.
# Dependency closure (DT_NEEDED plus dlopen targets) of the 32-bit Codec2 HIDL
# 1.2 HAL: the libcodec2_mtk_c2store store, the c2.mtk venc/vdec components it
# opens, libvcodecdrv and the codec libraries libvcodecdrv opens, and the
# 32-bit PowerVR gralloc mapper that libui loads into the HAL process.
# All ELFs are 32-bit ARM: the codec libraries only exist as such.
# Not listed, because they come from elsewhere:
#   libdrm.so: the platform's libdrm.vendor:32 (media.mk)
#   AOSP HIDL interfaces, libcodec2, libstagefright_*, libui, libfmq, ...:
#     built 32-bit .vendor variants (media.mk), except libstagefright_foundation:
#     the Android 12 build from prebuilts/vndk/v31, in /vendor/lib/r1-c2
#   lib64/ PowerVR userspace: vendor/rabbit/r1-pvr (64-bit only)
# Needs patchelf at import: lib/libcodec2_hidl@1.0.so, lib/libcodec2_hidl@1.1.so,
#   lib/libcodec2_hidl@1.2.so, lib/libcodec2_vndk.so and
#   lib/libavservices_minijail_vendor.so get --add-needed libr1_codec2_shim.so
#   (see shim/). Then these move to lib/r1-c2/ (installed as /vendor/lib/r1-c2),
#   because AOSP vendor_available modules own their names in /vendor/lib:
#   android.hardware.media.c2@1.0-1.2, libavservices_minijail_vendor,
#   libcodec2_hidl@1.0-1.2, libcodec2_hidl_plugin, libcodec2_soft_common,
#   libcodec2_vndk, libhwbinder, libsfplugin_ccodec_utils,
#   libstagefright_bufferpool@2.0.1. Finally every ELF gets
#   --set-rpath /vendor/lib/r1-c2 (bionic searches the caller's DT_RUNPATH for
#   DT_NEEDED and dlopen alike).
# lib/r1-c2/libcodec2_vndk.so also gets a 2-byte code fix (README.md, "Linking"):
#   at file offset 0x5096e, bytes e6 e7 (b 0x5193e) become 0e e0 (b 0x5198e),
#   after checking that d4 19 (adds r4, r2, r7) precedes them.
